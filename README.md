# PKIAdvisers Product Solutions

This repository provides customer-facing documentation, releases, and supporting resources for PKI automation solutions developed and maintained by PKIAdvisers.

## Solutions

### WinACME Framework

The WinACME Framework provides Windows-based certificate lifecycle automation for ACME certificate enrollment, renewal, and application deployment.

Current integrations include:

- Microsoft Remote Desktop Gateway
- Microsoft SQL Server Reporting Services (SSRS)
- Microsoft Exchange Hybrid
- Custom certificate deployment scripts

See [WinACME Framework](./WinACME-Framework/) for product information, installation instructions, release notes, and security information.

## Releases

Production releases are distributed through the GitHub Releases section of this repository.

Release packages may include digitally signed Windows executables and SHA-256 checksums for integrity verification.
